# AI Blog Automator for Android

このプロジェクトは、AI関連のニュースをRSSで取得し、Gemini、Claude、ChatGPTの3つのAIが討論形式で解説するブログ記事を生成して、noteに自動投稿（下書き作成・入力補助）するAndroidアプリケーションのソースコードです。

## 機能
*   **RSS取得**: 指定したRSSフィードから最新ニュースを取得。
*   **AI討論生成**:
    *   **Gemini**: ニュースの要約と技術的解説。
    *   **Claude**: 構成作成と司会進行。
    *   **ChatGPT**: 独自の視点提供と画像プロンプト作成。
*   **画像生成**: DALL-E 3を使用して記事のアイキャッチ画像を生成。
*   **note投稿補助**: WebViewを使用してnoteの投稿画面を開き、生成されたタイトルと本文を自動入力します。画像は生成されたURLを表示・リンクします。
*   **定期実行**: 毎朝8時にバックグラウンドで記事を生成し、通知でお知らせします。通知をタップすると投稿画面が開きます。

## 必要要件
*   Android Studio Ladybug | 2024.2.1 以降（推奨）
*   Android SDK API Level 34 (Android 14)
*   各AIサービスのAPIキー:
    *   OpenAI API Key (GPT-4, DALL-E 3)
    *   Anthropic API Key (Claude 3)
    *   Google Gemini API Key
    *   xAI API Key (Grok - オプション)

## ビルド手順

1.  **プロジェクトのインポート**:
    *   Android Studioを起動し、"Open" を選択して、この `AutoBlogApp` フォルダを選択してください。
    *   Gradle Syncが完了するのを待ちます。

2.  **リソースの確認**:
    *   `app/src/main/res/mipmap-*` フォルダ内のアイコン画像が含まれていないため、ビルドエラーになる可能性があります。
    *   解決策: Android Studioの "File" -> "New" -> "Image Asset" からアプリアイコンを作成してください。または、`AndroidManifest.xml` の `android:icon` と `android:roundIcon` をデフォルトのものに変更してください。

3.  **ビルドと実行**:
    *   AndroidデバイスをPCに接続するか、エミュレータを起動します。
    *   "Run" ボタン（緑色の再生マーク）をクリックしてアプリをインストールします。

## 使い方

1.  **APIキーの設定**:
    *   アプリを起動すると設定画面が表示されます。
    *   取得した各APIキーを入力してください。
    *   RSS URLはデフォルトでTechCrunchになっていますが、変更可能です。
    *   "Save Settings" を押して保存します。

2.  **noteへのログイン**:
    *   "Show/Hide Note Login WebView" ボタンを押し、noteのログイン画面を表示します。
    *   自分のアカウントでログインしてください。ログイン状態は維持されます。

3.  **手動実行**:
    *   "Run Manual Generation" ボタンを押すと、即座にニュース取得と記事生成が始まります。
    *   生成が完了すると、自動的にnoteの投稿画面（WebView）に切り替わり、タイトルと本文が入力されます。
    *   内容を確認し、画像リンクから画像をダウンロードして手動で貼り付けるか、そのまま公開ボタンを押してください。

4.  **定期実行（スケジュール）**:
    *   "Schedule Daily Run (8:00 AM)" ボタンを押すと、毎朝8時の実行が予約されます。
    *   毎朝8時頃に通知が届きます。通知をタップすると、生成された下書きがロードされ、note投稿画面に自動入力されます。

## 注意点
*   **noteの仕様変更**: noteのウェブサイトの構造（HTML/CSSクラス名など）が変わると、自動入力機能が動作しなくなる可能性があります。その場合は `NoteAutomator.kt` の修正が必要です。
*   **画像アップロード**: noteへの画像自動アップロードは技術的に困難なため、生成された画像のURLを本文に挿入する形式をとっています。画像ファイルとして表示させたい場合は、手動で画像を保存・アップロードしてください。
*   **APIコスト**: AI API（特にGPT-4やDALL-E 3）は従量課金制です。利用頻度にご注意ください。
